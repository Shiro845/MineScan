# MineScan ![.NET](https://img.shields.io/badge/.NET-10.0-blueviolet?logo=.net) ![Avalonia UI](https://img.shields.io/badge/Avalonia_UI-blue?logo=avaloniaui) ![C#](https://img.shields.io/badge/Language-C%23-blue?logo=csharp)

MineScan is a modern, high-performance reimagining of the classic "Minesweeper" logic puzzle, built on top of the .NET ecosystem and the Avalonia UI cross-platform framework. The application is strictly architected around the MVVM pattern using the modern CommunityToolkit.Mvvm library, guaranteeing loose coupling, clean code, and instantaneous reactive UI responses to user input.

The primary goal of the project is to combine authentic mathematical gameplay with advanced customization mechanics, a flexible localization system, and additional tactical tools that make the gaming experience more dynamic and engaging.
